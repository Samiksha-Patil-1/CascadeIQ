# CascadeIQ assistant instructions
At the start of every session read all files in memory/ and the sections of docs/ that relate to the task. Follow docs/RULES.md exactly. Work in the order given in docs/TASKS.md.
Before editing, state a plan and the files you will touch. Run tests after each change.
At the end of the session update memory/activeContext.md and memory/progress.md, and add any new decision to memory/decisionLog.md.
